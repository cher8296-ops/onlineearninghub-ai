# Android starter

This MVP package currently includes a mobile-responsive website, not a compiled APK.

To create an Android app later:
1. Install Node.js and Expo tooling on a computer.
2. Create an Expo project with `npx create-expo-app`.
3. Reuse the website/API design and connect it to the deployed backend.
4. Test on Android before producing a release build.

Do not publish an APK until authentication, privacy, security, and payment flows have been tested.
